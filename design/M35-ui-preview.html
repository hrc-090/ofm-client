OFM / UI · M36 NAV UPDATE

仪器台

不是给默认 Material 换一套蓝色，而是重定信息层级：状态是主角、数据可复制、分组靠细线。M36 把「模型 / 积分」合成一项、用分段开关切换，腾出的底栏格给网页搜索，从设置的二级页提到一级 dock。点导航切页、点上方的分段、可切深浅主题。

设计方向 · Instrument Panel

三条设计取舍

为什么长这样
01 / COLOR

暖纸 · 墨 · 朱砂

避开「靛蓝渐变 + 霓虹点缀」的泛 AI 配色。暖纸底降低长时间盯屏的疲劳，墨色承载正文，朱砂只出现在主开关、选中态和状态灯上，面积小但一眼可辨。

02 / HIERARCHY

细线代替卡片套卡片

原版首页每块信息都装进圆角卡片，视线被切碎。新版首屏状态直接摊开，用 1px 细线分组；卡片只留给真正需要成组的对象（渠道账号、模型条目）。

03 / DATA

机器字段与人读文字分离

URL、Key、模型 id、指标数字用等宽 + 大字重；说明文字用系统 sans。Base URL 与 Key 改成整行点击复制，不再需要「一行文字 + 两个按钮」。
